Stockroom プライバシーポリシー

制定日・最終更新日：2026年9月21日

Stockroom（以下「本ツール」）は、eBayでの販売に関する在庫、注文、発送および会計資料を、利用者自身がローカル環境で管理するためのツールです。本ポリシーは、本ツールがeBay APIを通じて取得する情報の取扱いについて説明します。

1. 取得する情報

本ツールは、利用者が許可した権限の範囲で、注文番号、商品情報、取引日時、購入金額、送料、配送先情報、購入者に関する取引上必要な情報、支払い・発送状況など、eBay注文の履行と管理に必要な情報を取得する場合があります。また、OAuth認証に必要なアクセストークンおよび更新用トークンを取り扱います。

2. 利用目的

取得した情報は、次の目的に限って利用します。

  • eBay注文、在庫、販売利益および発送状況のローカル管理
  • 購入者への商品の発送および取引の履行
  • 会計、税務および取引記録の作成・保管
  • 重複登録や誤登録の防止、障害調査およびセキュリティ確保
  • eBayから通知されるアカウント削除依頼への対応

取得情報を広告配信、利用者の追跡、人物評価、eBayと競合するデータベースの作成、または本ツールの目的と無関係な用途には使用しません。

3. 保存場所と保存期間

注文・在庫・販売および会計に関する情報は、原則として利用者が管理するローカル端末内に保存します。OAuth認証情報は、認証とAPI接続の維持に必要な範囲で暗号化またはアクセス制限された状態で保存します。情報は、取引の履行、法令上の保存義務、会計・税務上の必要性がある期間に限って保持し、その必要がなくなった場合は削除します。

4. 情報の保護

通信のHTTPS化、秘密情報の非公開化、アクセス制限、暗号化、最小権限のOAuth scope、重複防止およびログへの秘密情報の非記録など、情報の紛失、改ざん、不正アクセスまたは漏えいを防止するための合理的な安全管理措置を講じます。eBayのユーザーIDやパスワードを収集・保存しません。

5. 第三者提供

取得情報を販売、貸与または広告目的で第三者へ提供しません。ただし、法令に基づく場合、本人の同意がある場合、取引の履行に必要な配送事業者等へ必要最小限を提供する場合、またはeBay APIの運用とセキュリティ確保に必要な場合を除きます。業務委託先を利用する場合は、必要な範囲に限定し、適切な情報保護を求めます。

6. 削除および利用停止

eBayまたは対象となるeBay利用者から有効な削除要請を受けた場合、法令上の保存義務など正当な保持理由がある情報を除き、対象となる個人情報を速やかに削除します。また、利用目的に不要となった情報、eBay Developer Programへの参加終了時に保持が認められない情報、および不要となった中間コピーを削除します。OAuth連携を解除した場合は、不要となった認証情報を無効化または削除します。

7. eBayとの関係

本ツールは個人の業務管理用ツールであり、eBay Inc.またはその関連会社が提供、保証または推奨する製品ではありません。eBay APIから取得する情報は、eBay API License Agreement、eBay Privacy Noticeおよび適用法令に従って取り扱います。

8. ポリシーの変更

法令、eBayの規約または本ツールの取扱内容の変更に応じて、本ポリシーを改定する場合があります。改定後の内容はこのページで公開します。

9. お問い合わせ

本ポリシーおよびデータの取扱いに関するお問い合わせは、本ツールの管理者がeBay Developer Programへ登録している開発者連絡先を通じて受け付けます。
